# Addis Eats

A responsive single-page web application for ordering traditional Ethiopian food in Addis Ababa. Built as the **Module 2 Capstone Project** for the CodeOps Full Stack Software Development Program.

## Features

* Browse traditional Ethiopian dishes
* Search and filter menu items
* Add, remove, and update cart items
* Calculate order totals in ETB
* Persist cart data using `localStorage`
* Responsive design for mobile, tablet, and desktop
* Dynamic menu loading using `fetch()` and `async/await`

## Technologies

* HTML5
* CSS3
* JavaScript (ES6+)
* JSON
* LocalStorage API
* Git & GitHub


## Getting Started

```bash
git clone <your-repository-url>
cd addis-eats
```

Open `index.html` in your browser or run it with **VS Code Live Server**.

## Purpose

This project demonstrates practical skills in **responsive web design, DOM manipulation, JavaScript state management, asynchronous data fetching, array methods, and client-side storage**.
