Day 13 Exercises — CodeOps

The button element is a native HTML element that can be styled with CSS. Here, we have a button with the class btn-custom, which allows us to apply custom styles to it. You can change its background color, text color, padding, border radius, and more using CSS.

box-sizing: content-box vs border-box

content-box: declared width 300px, but padding + border are added on top, so it actually renders at 352px wide.
border-box: padding + border are included inside the 300px, so it renders at exactly 300px wide.

Specificity

This paragraph is targeted by an element rule (p), a class rule (.note), and an ID rule (#highlight) — all setting color.

Winner: the ID rule (crimson).
Specificity scores are counted as (ID, class, element):
p → (0,0,1)  ·  .note → (0,1,0)  ·  #highlight → (1,0,0)
Comparing left to right, any ID beats any number of classes, and any class beats any number of element selectors — so #highlight wins regardless of the order the rules are written in.
